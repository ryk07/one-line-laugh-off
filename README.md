# One-Line Laugh-Off

One original funny line, written by a small Python program (`main.py`) that
writes it to `/output/entry.txt`.

The line: a password manager that forgot its own password — the one tool
whose entire job is remembering — now sits in silence with its owner,
staring at the login screen together.
